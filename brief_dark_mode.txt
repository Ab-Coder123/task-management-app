# DARK MODE UI COLOR HANDLER BRIEF

## Objective
Harmonize, optimize, and enforce consistent, high-contrast, premium Dark Mode color handling across ALL pages and components in the Next.js Task Management app.

## Aesthetic Guidance (from Frontend Design Principles)
- **Palette**: Deep slate/navy tones (`#0b1120` base background, `#101828` / `#1e293b` elevated surfaces and cards, `#3b82f6` primary accent blue).
- **Typography & Contrast**: Ensure readable high-contrast foreground text (`#f8fafc` text-slate-50 / text-foreground) with soft muted labels (`text-slate-400` / `text-muted-foreground`).
- **Surface Elevation**: Cards, modals, inputs, and dropdowns must use dynamic semantically mapped classes or proper `dark:` modifier pairs (`bg-white dark:bg-card` or `bg-slate-50 dark:bg-slate-900/60`). Eliminate all hardcoded pure white backgrounds that break in dark mode or create stark unstyled white boxes.
- **Form Controls**: Select options, input fields, and modal containers must explicitly handle dark mode background and border colors (`border-border dark:border-slate-800`).
